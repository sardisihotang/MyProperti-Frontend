## 📌 Tentang Proyek / About the Project

**[ID]** Proyek ini adalah antarmuka pengguna (User Interface) berbasis web statis untuk agen properti (Real Estate). Dirancang untuk memudahkan calon pembeli mencari rumah impian mereka, aplikasi ini menampilkan daftar properti, detail harga, lokasi, serta terintegrasi dengan fitur Chat Widget interaktif untuk menjawab pertanyaan umum (FAQ).

**[EN]** *This project is a static web-based User Interface for a real estate agency. Designed to help prospective buyers find their dream homes, the application displays property listings, pricing details, and locations, and is integrated with an interactive Chat Widget to answer Frequently Asked Questions (FAQs).*

---

## 🚀 Fitur Utama / Key Features

**[ID]**
* **Katalog Properti:** Menampilkan daftar rumah/apartemen lengkap dengan gambar, harga, lokasi (terhubung ke Google Maps), dan deskripsi fasilitas.
* **Chat Widget Interaktif:** Fitur *bantuan langsung* (FAQ) di sudut layar yang memungkinkan pengguna memilih pertanyaan seputar KPR, harga, atau jadwal kunjungan.
* **Navigasi Terstruktur:** Terdapat menu untuk Lokasi, Tipe, Harga, Simulasi Kredit, dan Artikel.
* **Desain Responsif:** Tata letak yang beradaptasi secara optimal pada perangkat Desktop, Tablet, maupun Mobile.

**[EN]**
* **Property Catalog:** Displays a list of houses/apartments complete with images, prices, locations (linked to Google Maps), and facility descriptions.
* **Interactive Chat Widget:** A live-help (FAQ) feature floating on the screen, allowing users to select questions regarding mortgages, pricing, or visit schedules.
* **Structured Navigation:** Includes menus for Location, Type, Price, Credit Simulation, and Articles.
* **Responsive Design:** Layouts that adapt optimally across Desktop, Tablet, and Mobile devices.
